# Related projects

Other projects work on coding-agent instruction quality, including:

- [ai-context-kit](https://github.com/ofershap/ai-context-kit): instruction linting, measurement, and context selection.
- [YawLabs/ctxlint](https://github.com/YawLabs/ctxlint): checks instruction references against a codebase.

These descriptions summarize the projects' public documentation; they are not comparative benchmark results. ContextLint explores a conservative, evidence-first review flow with English and Chinese interfaces and self-contained visual reports.

The package is not published to npm. The scoped package name in `package.json` is project metadata, not a claim of npm name reservation.
